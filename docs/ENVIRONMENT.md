# Environment variables

| Variable                | Purpose                                                    | Required? | Development value        | Production value                | Security notes                                                                                                                                                      |
| ----------------------- | ---------------------------------------------------------- | --------: | ------------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_ENV`              | Runtime environment and seed safety check                  |       Yes | `development`            | `production`                    | Production disables the dev seed.                                                                                                                                   |
| `APP_MODE`              | Application mode label                                     |       Yes | `development`            | `production`                    | Mock mode should not be exposed as live payments.                                                                                                                   |
| `PAYMENT_MODE`          | Payment provider selection                                 |       Yes | `mock`                   | Provider-specific               | Production provider must be verified server-side.                                                                                                                   |
| `EMAIL_MODE`            | Email adapter selection                                    |       Yes | `mock`                   | Provider-specific               | Never log private message content in production.                                                                                                                    |
| `SMS_MODE`              | SMS/OTP adapter selection                                  |       Yes | `mock`                   | Provider-specific               | Local recovery codes are returned only outside production, expire after five minutes, and are rate-limited. Use a provider and shared secure storage in production. |
| `STORAGE_MODE`          | File storage selection                                     |       Yes | `local`                  | Provider-specific               | Validate and scan uploaded files in production.                                                                                                                     |
| `WEB_ORIGIN`            | Allowed CORS/browser origin                                |       Yes | `http://localhost:3000`  | Exact HTTPS origin              | Do not use wildcard origins with credentials.                                                                                                                       |
| `API_ORIGIN`            | Next.js rewrite destination for the Nest API               |        No | `http://localhost:4000`  | Internal API origin             | Keep private network boundaries.                                                                                                                                    |
| `API_PORT`              | NestJS listen port                                         |        No | `4000`                   | Platform assigned               | Bind behind a TLS proxy.                                                                                                                                            |
| `DATABASE_URL`          | PostgreSQL connection                                      |       Yes | Compose local URL        | Secret-managed URL              | Use least-privilege DB credentials and TLS.                                                                                                                         |
| `REDIS_URL`             | Redis/BullMQ connection                                    |       Yes | `redis://localhost:6379` | Secret-managed URL              | Require network isolation and authentication in production.                                                                                                         |
| `JWT_ACCESS_SECRET`     | Access-token signing key                                   |       Yes | Replace placeholder      | Cryptographically random secret | Never commit; rotate deliberately.                                                                                                                                  |
| `ACCESS_TOKEN_TTL`      | Access-token lifetime                                      |        No | `15m`                    | Short duration                  | Avoid long-lived bearer tokens.                                                                                                                                     |
| `REFRESH_TOKEN_TTL`     | Refresh-session lifetime                                   |        No | `7d`                     | Risk-based duration             | Sessions are revocable; current code uses a seven-day rotation window.                                                                                              |
| `COOKIE_SECURE`         | Enables Secure cookie attribute                            |        No | `false` for localhost    | `true`                          | Must be true over HTTPS.                                                                                                                                            |
| `COOKIE_SAME_SITE`      | SameSite cookie policy                                     |        No | `lax`                    | `lax` or `strict`               | Review CSRF risk if changed.                                                                                                                                        |
| `MOCK_PAYMENT_DELAY_MS` | Simulated provider delay                                   |        No | `1200`                   | Not used                        | Mock integrations must be disabled in production.                                                                                                                   |
| `DEMO_USER_PHONE`       | Fictional development seed account phone                   |        No | `9000000001`             | Do not set                      | Development-only account; change in shared environments.                                                                                                            |
| `DEMO_USER_PASSWORD`    | Fictional development seed password, hashed before storage |        No | `DemoPass!234`           | Do not set                      | Development-only; use a unique password for shared environments.                                                                                                    |

Copy `.env.example` to `.env`. Treat every real environment file as a secret and keep it out of Git.
