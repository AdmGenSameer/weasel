# Contributing

1. Add observable behavior and uncertainty to `docs/FEATURE-INVENTORY.md` before implementation.
2. Keep account, payment, and authentication logic in the API.
3. Use fictional seed data only; do not copy private production account data.
4. Add tests for business rules and update API/environment documentation with changes.
5. Run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build` before submitting.
6. Keep `.env`, build artifacts, logs, and local database files out of version control.
